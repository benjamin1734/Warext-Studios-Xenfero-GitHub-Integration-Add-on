# Warext GitHub Sync v1.0.2

## Türkçe

Bu sürüm, Admin CP erişimini ve GitHub Sync navigasyon görünürlüğünü düzeltir.

### Değişiklikler
- Üst seviye Warext GitHub Sync kategorisine eksik GitHub ikonu eklendi.
- Dashboard, Connections, Repositories, Mappings, Templates, Actions, Health, Conflicts, Webhook Logs ve Diagnostics erişim yolları dokümante edildi.
- `wghManage` yetkisi ve Admin CP navigasyon yenileme adımları kurulum belgesine eklendi.

---

## English

This release fixes Admin CP navigation visibility and documents the GitHub Sync access paths.

### Changes
- Added the missing GitHub icon to the top-level Warext GitHub Sync category.
- Documented Dashboard, Connections, Repositories, Mappings, Templates, Actions, Health, Conflicts, Webhook Logs and Diagnostics access paths.
- Added the `wghManage` permission and Admin CP navigation refresh steps to the installation guide.
